# AI Smart Sourcing — Dubai Chambers

AI-powered vendor proposal evaluation system for Dubai Chambers, featuring DESC compliance, multi-language support (EN/AR), and Sigma Intelligence tracking.

## Architecture

- **Backend**: FastAPI (Python) with Supabase, deployed on Railway
- **Frontend**: React + Vite + Tailwind CSS, deployed on Vercel
- **Database**: PostgreSQL (Supabase) with 14 tables, RLS policies, and pgvector

## Backend Setup

```bash
cd backend
pip install -r requirements.txt

# Set environment variables (see .env.example)
export SUPABASE_URL=...
export SUPABASE_ANON_KEY=...
export SUPABASE_SERVICE_ROLE_KEY=...
export SUPABASE_JWT_SECRET=...

uvicorn main:app --host 0.0.0.0 --port 8000
```

API docs available at `/docs` (Swagger) and `/redoc`.

## Frontend Setup

```bash
cd frontend
npm install
npm run dev     # Development server on port 3000
npm run build   # Production build
```

Set `VITE_API_URL` and `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` environment variables.

## Database

Run `database/migration.sql` against your Supabase PostgreSQL instance. Requires `uuid-ossp` and `vector` extensions.

## Deployment

- **Railway** (backend): Auto-deploys from `backend/` using the `Procfile`
- **Vercel** (frontend): Import the repo, set root directory to `frontend/`
